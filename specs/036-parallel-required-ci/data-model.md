# Internal CI evidence
Backend manifests record source SHA, index/count/mode, complete collection/assignment and parsed execution counts; raw JUnit stays local. Coverage databases use only repository-relative app paths with a fail-closed path check before upload; combined per-line contexts must equal the shard union. Mutation manifests record complete requested/assigned scope, explicit empty parts, per-file mutant identities and exported counters. New evidence rejects workspace/home/temp roots rather than exporting them. Existing Allure diagnostics and retention remain unchanged. No runtime schema, persistence ownership, API or account data changes.
