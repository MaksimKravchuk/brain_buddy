## Contracts and failure handling
scripts/ci_shards.py is standard-library code; pytest plugin hooks use passed objects without importing pytest for utility tests. CLI operations: backend collection manifest/argument generation; backend result/manifest merge validation and diagnostic copying; mutation scope selection; mutation per-shard result recording; mutation aggregate validation/summing. Pass paths explicitly and candidate SHA/index/count through arguments/environment. Reject malformed/missing/duplicate indexes, inconsistent collection or source/mode, incomplete/overlapping assignments, mismatched JUnit counts, XML failures/errors, wrong scope/files, overlapping mutant identities, invalid totals or interruption. Missing uploads/downloads fail. Artifacts contain synthetic test IDs, compiler/test outputs and counts only; no credentials, user content or account data. No new retention policy (reuse PR 7 days, others 30). No account export/purge impact for source-derived CI evidence.
