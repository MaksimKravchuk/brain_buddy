# Research decisions
Use two deterministic backend partitions and two complete mutation partitions on isolated standard Linux runners; iOS app and macOS package tests run on separate existing Mac runner classes. Existing xdist already uses four cores, so adding more workers to one runner is not the proposal. Module mutation split tree_service/rest balances measured CPU work. Keep full test-collection/assignment manifests, JUnit count checks, combined raw coverage, explicit scope and mutant identity manifests; aggregate counters under the existing gate. Reject missing parts instead of interpreting partial uploads as a pass. Do not optimize Argon2, shared mutable fixtures, snapshots, Allure rules or test scope in this change.
