Transcript-first voice brain dump — screens

Retro design of shipped surfaces. Every screen is drawn at the 390×851 viewport of the founder’s screenshots, with the desktop difference noted on each sheet. This page is a contact sheet, not a screen: it carries no id and no requirement.

Copy is quoted from frontend/src/features/brain-dump/BrainDumpRoute.tsx and mobile/src/app/brain-dump/[operationId].tsx as shipped; where a screen does not satisfy a requirement the divergence is marked on the state rather than designed away. The inventory, the state tables and the affordance → requirement map are in design.md.
