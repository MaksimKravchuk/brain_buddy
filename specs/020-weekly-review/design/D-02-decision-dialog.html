D-02 · Decision dialog with the AI navigator — web

A 560 px modal dialog (20 px radius, floating shadow, light blurred scrim) opened from a marker chip in D-01, from the task's inline detail, or embedded in the review (D-03). Content, order, reason → recommendation mapping and copy match M-03/M-04. Keyboard: focus lands on the dialog title; Tab moves through reasons then decisions; number keys 1–7 pick a decision; Esc closes without changes and returns focus to the marker chip that opened it.

On web every suggestion uses the cloud provider, so the first "Suggest" always goes through consent (FR-024). Every failure shows a correlation ID (FR-025, FR-045). Server round-trips show a pending state on the chosen control only. Every applied decision shows an Undo toast for about 5 seconds (FR-048).
