M-07 · Cloud provider consent, cloud suggestions and failures (iOS)

Every cloud request is preceded by a one-time consent that names the provider and lists exactly what is sent (FR-024, Clarification 3): title, notes, chosen reason, project name, and titles of up to 20 other open tasks in the project. The same list is used for on-device and cloud. Consent is per provider, revocable in Settings, and a revoked consent stops requests immediately. Web (D-02) uses the same screen and copy in a dialog.

Every cloud failure names the cause, shows the correlation ID (FR-025, FR-045), and leaves the card usable. Provider name is illustrative.
