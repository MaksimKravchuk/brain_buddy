M-11 · Review entry, mode picker and resume — iOS

The deferred "Weekly review · coming later" row in ListsHubScreen becomes a working row in its own section, still apart from the four lists: it is not a fifth list (ADR-0006, FR-042). Its metadata is the neutral "Last review: N days ago" (FR-038). The review opens as a full-screen cover, like Process inbox. The review can be started any time (FR-027); the scheduled notification (M-25) opens the same entry.

Order on open: onboarding (M-12, first time only) → While you were away (M-09, if unseen parks) → restart mode (M-10, if 21+ days) → resume or mode picker (here) → steps.
