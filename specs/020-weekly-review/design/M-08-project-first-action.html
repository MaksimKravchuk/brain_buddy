M-08 · Project without a next action — AI first next action (iOS project screen)

Extends the existing "This project needs a next action" row on the project screen (TaskListScreen → ProjectStatusRow) with "Suggest a next action". Input is the project name and its open task titles only (FR-019). Confirming creates the task in Next in that project (US3-8). On-device, unavailable-model and cloud states are the same as M-05, M-06 and M-07. The review's "Projects without a next action" step (M-19) uses this same block.
