M-23 · Settings — Weekly review and Suggestions sections (iOS)

Two new sections in the existing Settings screen. Weekly review: day, time, threshold (FR-035, FR-039), and the neutral "Last review" line (FR-038), which is information, not a control. Suggestions: whether Apple's on-device model is available here, what to use when it isn't (FR-023, remembered choice), the downloaded model with its size and a delete action (FR-049), and cloud consent with revoke (FR-024). No streaks, no history chart.

Delete model is the only destructive action here and asks for confirmation; it states what is lost. Rose is used only for that destructive control, never for age.
