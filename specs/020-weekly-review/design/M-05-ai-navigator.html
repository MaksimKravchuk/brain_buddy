M-05 · AI navigator inside the decision card — on-device (iOS)

Shown inside the "Find a first step" and "Reformulate" forms (M-04) after "Suggest". It uses Apple's on-device model when available (FR-022): no server request, no consent prompt, works offline, and a short line says so. The navigator panel uses neutral white with a sky Compass, not the emerald/Sparkles tokens, which stay reserved for the speculative Execution exploration.

Input is exactly title, notes, chosen reason, project name and up to 20 other open task titles in the project (FR-019). Proposals are 1–3, never duplicate an open task in the project, and never add people, places, amounts or dates not already in the task (FR-021). Picking fills the field; only "Save" writes (FR-020).
