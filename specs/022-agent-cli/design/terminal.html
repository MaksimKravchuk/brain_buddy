BrainBuddy in your terminal

Proposed interface · D-01 and D-02 · synthetic data only · no published release yet

One command per action. Compact JSON goes to stdout; structured errors go to stderr. No prompts during agent work.

D-01 · Capture, inspect, act

$ bb commands task
{"name":"task","commands":["add","list","get","update","transition"]}

$ bb task add --title "Call the garage" --idempotency-key garage-1
{"data":{"id":"task-demo","title":"Call the garage","state":"inbox","revision":1}}

$ bb task list --query garage --limit 20 --fields id,title,state,revision
{"data":[{"id":"task-demo","title":"Call the garage","state":"inbox","revision":1}],"page":{"has_more":false,"next_cursor":null}}

$ bb task update task-demo --revision 1 --json @- --idempotency-key garage-2
stdin: {"title":"Call the garage and book the repair"}
{"data":{"id":"task-demo","title":"Call the garage and book the repair","state":"inbox","revision":2}}

$ bb task transition task-demo complete --revision 2 --idempotency-key garage-3
{"data":{"id":"task-demo","title":"Call the garage and book the repair","state":"completed","revision":3}}

D-01 · Recover deliberately

Stale revision · stderr · nonzero exit
{"error":{"code":"conflict","status":409,"message":"Revision conflict","reference_id":"demo-reference","detail":{"current_revision":3}}}

Interrupted write · stderr · nonzero exit
{"error":{"code":"transport","message":"Request failed; delivery is unknown","delivery_unknown":true,"idempotency_key":"garage-3"}}

Reread before retrying a stale edit. Recover uncertain delivery using the same key and identical input according to the server contract. Credentials never appear in output or previews.
