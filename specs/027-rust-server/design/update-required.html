Update required

027 FR-018: a client build older than the release is refused with an actionable error and nothing is written. No new screen is added. The refusal reuses existing surfaces: the 026 sync status and recovery states on iPhone and Mac, the existing error alert for direct requests, and on the web a persistent alert variant of the shell toast. iPhone on the left, Mac on the right. Buttons are illustrative.

Older builds are recognised by the integer header X-Client-Epoch: missing or lower is refused. The marketing version is not used. The refusal appears only after the server explicitly answers UPGRADE_REQUIRED. Offline, timeouts, server errors and unreadable responses never show it.

M-01 / D-01 · Update required on iPhone and Mac

Default (.01): the existing sync row and details switch to the 026 “Update needed to sync” state, now with the reference ID. Local editing continues; sync stops. Old builds at this cutover show their shipped 026 body instead (“Your saved tasks and waiting changes stay on this device.”); this release no longer makes that promise.

The app can't tell yet whether an update is needed, so it doesn't say so. A refusal already received stays shown until the app is updated or a later request succeeds.

.04 · Direct request refused

This version of Brain Buddy is out of date. Update it to continue. Nothing in your account was changed. Reference ID: demo-027-upgrade-02.

Existing error alert for sign-in, account, voice and AI requests. The text is the server's message. Modal; initial focus OK; Escape (Mac) or OK dismisses; focus returns to the control that made the request.

Timeouts, 5xx and unreadable answers keep the 026 error state. They are never shown as “Update needed”.

D-02 · Update required on the web

The web app ships with the server, so only a tab opened before a release can be older. The shell's text toast is role="status" and disappears after 2.6 s, so it can't carry this. D-02 adds one persistent alert variant: role="alert", no auto-dismiss, Reload and Dismiss, and the existing (ref: …) suffix. It is fixed at top centre under the top bar and placed there in DOM order. It does not take focus; Tab from the top bar reaches Reload; Escape dismisses it.
