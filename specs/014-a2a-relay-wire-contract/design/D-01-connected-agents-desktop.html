D-01-S04empty (filtered to nothing) — deliberately absent

No filter, no search, no sort on this list

A connection list is small and every row is safety-relevant, so nothing here can hide a row. Adding a filter would be an affordance with no requirement behind it — FR-001 asks only for create, test, inspect, update, rotate and disconnect. The nearest real “filtered to nothing” in this feature lives on D-02-S05: connections exist, but none is eligible to receive a hand-off.

Connecting an agent

D-01-S08add an agent — bearer token scheme

There is no signing-secret step and no inbound-secret sheet. Push notifications use a per-run token BrainBuddy registers with the agent automatically; you never see or configure it.

Add an agent

BrainBuddy reads the agent's published card, then stores your credential sealed and never shows it again. Adding an agent re-checks your password.

D-01-S20connection: the agent changed since the last test

FR-002 names this condition **Agent changed** and FR-014 fixes the wording; AC-012 and FR-004 govern the refusal. A changed connection behaves as untested until a new successful test. A run already dispatched keeps observing at the interface recorded at dispatch; it is never redirected to an untested one.

Rollout, rotation and disconnect

D-01-S22rollout OFF

007 FR-019, narrowed by FR-016: observation of already-dispatched runs and verified push handling continue while rollout is off.

The external-agent relay rollout is off. Adding, editing, testing and rotating credentials are unavailable. Existing connections stay visible and can still be disconnected, and runs already dispatched keep reporting.

D-01-S23disconnect — confirmation dialog

AC-022. The confirmation says exactly what is destroyed and exactly what is not stopped.

This cannot be undone

Disconnect Hermes planner

Close

BrainBuddy destroys the stored credential, stops observing this agent's runs, stops registering push notifications for them, and refuses new hand-offs and replies through it. Active runs become Connection disconnected. Disconnecting does not cancel work the agent already accepted.

Existing run history stays, redacted, until it expires.
