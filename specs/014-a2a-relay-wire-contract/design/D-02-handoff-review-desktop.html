Feature 014 · A2A relay wire contract · design

D-02 · Hand-off review (desktop)

The one screen where task content is authorised to leave BrainBuddy. Opened from a Task; it lists the exact text that will be sent, the destination, the guarantee tier and the cancellation disclosure before anything is dispatched. Static and non-interactive.

The consent boundary

AC-007 / FR-005. Nothing leaves BrainBuddy until this exact list has been read. Confirmation names the manifest token behind the scenes; changing any value, the destination or the run ID invalidates it.
