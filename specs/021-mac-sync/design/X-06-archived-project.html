X-06 · Archived project: archive keeps its tasks, and unarchive (macOS)

The Mac already archives losslessly and can restore a project, but only while local-only (isLocalWorkspace). After this feature the same behaviour holds signed in, and the server keeps it for every client (ADR-0020, FR-024 – FR-026). Archiving hides the project from active navigation and keeps every task's project; an archived project takes no new tasks; unarchive brings it back with the same tasks.

Verb: "Unarchive", as in the spec, ADR-0020, the iPhone (M-02) and the web (D-01). The Mac's existing "Restore project" item and its "Restore the archived project…" messages change to "Unarchive" so the three clients say the same thing (list of strings at the end).
