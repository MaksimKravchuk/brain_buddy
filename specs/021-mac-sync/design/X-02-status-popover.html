X-02 · Sync status popover (macOS)

Opens from the status words in the sidebar footer (X-01), anchored above them. Small and non-modal: an NSPopover with transient behaviour, closed by Esc or a click outside, never blocking the window (FR-016, FR-017). It holds everything FR-016 lists: the exact last-sync time, how many changes are waiting and the age of the oldest, the sync issues in plain words with a reference ID and Dismiss, "Sync now", and the signed-in email with "Sign out…". Width 320 pt; the issue list scrolls inside it after about three issues.

Issue wording follows the iPhone's Sync issues screen: what was attempted, why it failed, the reference ID, the time. Example issues come from the spec's edge cases. Reference IDs are the request's X-Correlation-ID; the Mac sends its own ID, so a timeout with no reply still has one the server logs can match (FR-015).

Keyboard, VoiceOver and closing

  • Open: click, Space or Return on the status words. The popover is announced as "Sync status" and VoiceOver reads its content in order (status notice, last synced, waiting, issues count) before the first control (FR-016).
  • Tab order: attention action (Sign in again / Copy) → each issue's Copy → Dismiss → Sync now → Sign out…. Shift-Tab reverses. "Sync now" is skipped only offline, the one state where it is disabled. It stays enabled and focusable during a sync (FR-013).
  • Sync now while syncing: a press joins the running sync, or queues a single follow-up sync (single-flight). There is no visual or spoken change; the footer indicator is the only sign of activity.
  • Close: Esc, a click outside, or choosing "Sign in again" or "Sign out…" (which open X-03 / X-04). Focus returns to the status words in the footer.
  • Live updates while open: the times and counts update in place without moving focus. A new issue arriving while the popover is open is appended and announced politely; focus stays where it was (FR-009).
  • Never modal: the window behind stays fully usable; typing in the window closes the popover like any transient popover.
