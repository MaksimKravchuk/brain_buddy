X-07 · Menu bar: "Sync now" and the account items (macOS)

FR-006 needs a "Sync now" command in the menu (and in the popover, X-02) that is never needed. It goes in the File menu with ⌘R, the shortcut people already try for "refresh"; the Mac app uses no ⌘R today. The account action goes where macOS apps keep it, in the app menu: "Sign in…" when account-less, "Sign out…" when signed in, "Sign in again…" when the session ended (FR-001). Today's toolbar "Refresh" button is removed: with background sync it has nothing left to do, and keeping it would suggest manual refresh is needed (owner intent, SC-007).

Our items use sentence case ("Sync now", "Sign out…"), as all product copy does; this differs from the macOS habit of title case and is deliberate. System items (Hide, Quit, Close) keep macOS's own wording.

Behaviour

  • ⌘R works from anywhere in the main window, including while typing in a field (it does not insert text). It does the same as "Sync now" in the popover; the popover is not opened.
  • No menu item opens a dialog except "Sign in…" (X-03) and "Sign out…" (X-04), both started by the person (FR-017).
  • Loading, empty, error and partial-failure states are n/a for menus: the menu reflects the footer state and never shows its own message.
