X-03 · Sign-in sheet (macOS)

A window-attached sheet, opened by "Sign in to sync" in the footer (X-01), "Sign in…" / "Sign in again" in the popover (X-02) or the app menu (X-07). It replaces today's full-window signIn view and the full-window overlay shown when a session expired: the Mac is now usable without an account (FR-002), and an ended session never covers the window (US3-5). "Try local voice capture" goes away because voice works account-less. "API URL" becomes the iPhone's "Advanced › Server address".

Copy is the iPhone's (SignInSheet.swift, SyncEngine.signInFailure) with "Mac" for "iPhone". Sign-in is the only Mac action that needs a connection (FR-001). This sheet is a dialog the person starts, so FR-017 allows it.

Account deletion cancelled by signing in (FR-017, gap G-3 resolved)

  • The note appears only after a sign-in that actually cancelled a pending deletion. It is shown once, in this sheet, before the sheet closes. There is no extra alert.
  • The copy is the iPhone's (SignInSheet.swift): "Your account deletion was cancelled" / "Signing in cancels a deletion you requested in the last 14 days. Delete your account again on the web if you still want to."
  • Focus goes to the note, and "OK" is the only button. Return or Esc closes the sheet, and focus returns to the control that opened it, or to the X-01 status words when that control no longer exists (a closed popover, the vanished "Sign in to sync", a menu item).
